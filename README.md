# 🧩 Power BI Superstore Dashboard  

## 📋 Project Overview  
This project analyzes the **Superstore dataset** to uncover valuable insights about **sales, profit, discount behavior, and customer performance** across different regions and categories.  
The analysis process integrates **Excel**, **SQL**, and **Power BI** to ensure a complete data analysis workflow — from raw data cleaning to business visualization.  

---

## 🧠 Tools Used  
- **Excel** – for data cleaning and preprocessing  
- **SQL** – for data exploration and aggregation  
- **Power BI** – for dashboard design, visualization, and insight reporting  

---

## ⚙️ Data Analysis Workflow  
1. **Excel:**  
   - Cleaned the dataset (removed duplicates, handled missing values).  
2. **SQL:**  
   - Queried and summarized data to extract important insights before visualization.  
3. **Power BI:**  
   - Built four interactive pages showing sales, profit, regional performance, and customer insights.  
   - Added slicers and filters for dynamic exploration (Year, Category, Ship Mode).  
   - Designed KPIs and charts for clear storytelling.
